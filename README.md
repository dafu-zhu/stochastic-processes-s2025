# Stochastic Processes - Spring 2025

Comprehensive lecture notes for a undergraduate-level Stochastic Processes course at Xiamen University, Spring 2025.

## 📚 About

These are my personal lecture notes taken during a Stochastic Processes course. This course focused heavily on proofs, with just enough examples to instantiate the concepts. This lecture note is written in **Chinese**.

## 📄 Lecture Notes

**Access the full PDF:** [Stochastic Processes Notes (PDF)](https://dafu-zhu.github.io/stochastic-processes-s2025/notes.pdf)

or download at the release page.

## 📖 Topics Covered

The lecture notes cover the following major topics:

- **Probability Review**: Probability spaces, random variables, expectation, and conditional probability
- **Discrete-Time Markov Chains**: Transition matrices, stationary distributions, classification of states
- **Poisson Processes**: Arrival times, compound Poisson processes, transformation of Poisson processes
- **Continuous-Time Markov Chains**: Birth-death processes, Kolmogorov equations
- **Martingales**: Definitions, stopping times, optional stopping theorem
- **Brownian Motion**: Construction, properties

## 📋 Prerequisites

To fully understand these notes, you should have:
- Strong foundation in probability theory
- Calculus and real analysis
- Linear algebra
